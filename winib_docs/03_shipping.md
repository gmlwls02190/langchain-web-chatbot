# 위니브 카페 배송 정책

## 1. 배송비

| 구분 | 배송비 |
|------|--------|
| 기본 배송비 | 3,000원 |
| 5만원 이상 구매 | 무료 |
| 제주 지역 | 기본 배송비 + 3,000원 |
| 도서산간 지역 | 기본 배송비 + 3,000원 |

- 5만원 이상 구매 시 기본 배송비는 무료이나, 제주·도서산간 추가비
  (3,000원)는 별도로 부과됩니다.

## 2. 배송 기간

- 평일 **오후 2시 이전** 결제 완료 건은 당일 발송됩니다.
- 오후 2시 이후 결제 건은 다음 영업일에 발송됩니다.
- 발송 후 도착까지 보통 1~2일 소요됩니다.
- 제주·도서산간은 2~4일이 소요될 수 있습니다.
- 주말·공휴일은 발송되지 않습니다.

## 3. 원두 로스팅 일정

- 원두는 신선도를 위해 **주문 후 로스팅(주문 로스팅)** 으로 발송됩니다.
- 로스팅은 매주 화·금요일에 진행되며, 해당 요일 직전 주문이 함께
  발송됩니다. 이로 인해 원두 단일 주문은 최대 3~4일이 소요될 수 있습니다.
- 원두와 일반 상품을 함께 주문하면 로스팅 일정에 맞춰 합포장 발송됩니다.

## 4. 배송 조회

- 마이페이지 > 주문내역에서 송장번호로 실시간 조회가 가능합니다.
- 발송 완료 시 등록된 휴대폰으로 알림 문자가 발송됩니다.

## 5. 배송 관련 안내

- 택배사는 일반 택배(CJ대한통운)를 이용합니다.
- **새벽배송·당일배송 서비스는 운영하지 않습니다.**
- 부재 시 택배사 정책에 따라 경비실 위탁 또는 재배송됩니다.
- 배송지 오기입으로 인한 반송 시 재발송 배송비는 고객이 부담합니다.

## 6. 해외 배송

- 현재 해외 배송은 지원하지 않습니다. 국내 배송만 가능합니다.
